# 标准地图与复刻地图对比工作台 (Standard Map Compare Workbench)

在线地图对比与审图核验平台。支持自然资源部标准地图规范底图（中国横版/竖版、各大洲、世界地图）与制图复刻图层的视口同步联动、卷帘对比与透明叠置核验。

---

## 核心功能

1. **主视窗对比模式**
   - **卷帘对比 (Swipe Curtain)**：支持水平与垂直双向卷帘切分，拖动分割线比对底图与复刻图层要素吻合度。
   - **双屏联动 (Sync Dual-View)**：左右或上下双视口同步缩放与平移，光标位置十字准星跨视口定位。
   - **透明叠置 (Opacity Overlay)**：单视口重叠展示，支持 0%~100% 透明度连续渐变及正常、正片叠底、差值混合模式。
   - **光标中心缩放**：采用标准 GIS 仿射变换不变式，缩放时鼠标指针下的地理坐标像素位置保持锚定。

2. **地图分类库**
   - **中国地图系列**：包含 1:740万 横版标准底图与 1:1000万 竖版陆海统筹底图（附小地球视图）。
   - **各大洲系列**：涵盖亚洲（1:2500万）、欧洲（1:1150万）、非洲（GS(2023)2758号）、北美洲（1:2100万）、南美洲（1:1750万）、大洋洲（1:2300万）、南极洲（1:1250万）标准大洲图。
   - **全球系列**：涵盖等差分纬线多圆锥投影世界地图（1:5700万 4开轮廓图）与经纬度等间隔直投世界地图（小8开冷色版）。

## 本地运行与开发

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务
npm run dev

# 3. 生产构建
npm run build
```

## 自动化部署 (GitHub Pages)

项目配置了自动化部署工作流（`.github/workflows/deploy.yml`）。当代码推送到 `main` 分支时，GitHub Actions 会自动触发构建并将 `dist` 目录发布至 GitHub Pages。

## 地图数据与规范说明

本项目标准地图底图源自[自然资源部标准地图服务系统](http://bzdt.ch.mnr.gov.cn/)，完整规范呈现中国陆海疆域、南海诸岛、十段线、钓鱼岛与赤尾屿。复刻图层由 OpenQGIS / NOWZoom 基于标准底图与相应投影参数进行 1:1 制图配准。
