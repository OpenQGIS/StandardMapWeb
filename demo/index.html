按钮形态变换与弹性触感增强

在 StandardMapWeb 中，现有 Header 工具栏和画廊包含了【主题切换】、【卷帘对比方向切换】、【双屏分屏切换】、【对调图层】、【画廊折叠】等核心操作。传统切换往往缺乏连续感；而借助本地调用 Morphicons 算法库，矢量图标能在用户点击瞬间通过弹簧阻尼平滑重组变形，带来令人惊艳的微交互品质。

主题切换 (三态闭环) Monitor → Sun → Moon

显示器收聚为太阳，阳光收敛为上弦月，月亮平滑舒展变回显示器。

点击切换
卷帘对比方向 Vertical ↔ Horizontal

分割中缝与两翼区块在弹簧阻尼驱动下，自适应旋转与重组。

点击变向
双屏同步并排 Columns ↔ Rows

左右双列平滑对偶变形为上下双行，分割线解构重塑。

点击切换
对调图层 / 顺序 ArrowLeftRight ↔ Repeat

箭头端点与流向在点击瞬间发生反向流动与物理弹簧形变。

点击反转
地图画廊开关 Grid ↔ ChevronDown

四格缩略图矩阵收束为收起箭头，关闭时从箭头绽放回画廊矩阵。

展开 / 收起
收起顶栏 / 沉浸全屏 ChevronUp ↔ ChevronDown

尖角箭头在点击时弹性反转，引导全屏沉浸视界。
